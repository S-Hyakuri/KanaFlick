# かなフリック · KanaFlick

日语打字与词汇学习应用，当前开发版本 **0.9.4 / 22**（设备验收未完成）。中文界面，使用系统输入法。

## 使用

应用请求系统输入法关闭候选建议，但不强制控制键盘候选栏；不同 IME 是否采纳取决于其实现。浊音／小假名／罗马字转换的末尾中间态暂不计错，同一未修改错误不会因后续输入重复罚分。支持日语 12 键与 QWERTY 输入。平片假名等价（如「コーヒー」可输入「こーひー」）；末尾罗马字等待转换，不因组合标记缺失而判错。小假名前置的大假名暂不判错，输入下一个假名后才判断；例如「きや」等待修改为「きゃ」，「きやく」则判错。

- **单词练习**：选择 N5–N1 或自定义词库，点击“开始练习”。每次输入变化立即逐字判断，包括组合中的假名；正确前缀显示进度，完整输入原文或词条提供的假名读音后自动推进。例如“学校”和“がっこう”均正确，无须点选候选。忽略标点与符号，保留长音符「ー」。
- **句子练习**：在主页品牌下切换模式，选择参考等级及篇目。支持句子的完整假名或对应原文，实时匹配前缀推动提示；改错可回退，错误不清空整句。整篇依次完成，跳过单独计句数。
- **阅读库**：点击“查看所有阅读”，按等级浏览卡片，查看全文、展开假名和来源，或点击“练习这篇”。全文离线可读，外部来源链接需要浏览器及网络；没有搜索框。
- **学习**：按等级浏览不含符号的词条；每页 30 词，可直接练习当前等级词汇。
- **假名输入熟练度**：学习页进入，按五列五十音图分组查看基础音、浊音／半浊音、拗音／外来音及小假名。点击单元查看有效样本、错误样本、近期错误倾向和日期；平片假名合并，状态有文字说明。页尾可确认重置。列表逐行加载，跨底栏切换保留页面和滚动位置；大字体时可横向滚动。
- **选项**：使用圆角描边分组与图标列表，保存每局 5/10/20 词；“根据薄弱假名安排词汇”默认关闭，只影响下一次从词库开始的单词抽样，保留随机探索，不跨词库补题。查看帮助、GitHub 信息、来源与许可证；“关于 KanaFlick”仅保留一个 [GitHub 仓库](https://github.com/S-Hyakuri/KanaFlick)入口，以圆角描边卡片显示仓库名与完整网址，整卡可点击打开，网址可选择复制。

熟练度与练习计分独立：只统计目标全文可解析为支持假名的题目，汉字目标不推断按错的假名；正确前缀、恢复文本不产生样本，浊点／小假名与罗马字转换的末尾中间态暂不计错；可观察的组合假名参与实时判断。汉字完成不虚构假名成功样本。每题同一单元最多一个样本，明确出错后改对仍记该单元错误，跳过和提前退出只结算已明确的错误。少于 8 个样本仅积累，达到 8 个且近期错误倾向 ≥0.30 才参与薄弱加权。含汉字的词可凭可靠读音参与推荐，但未必反馈画像，句子练习可继续积累。关闭推荐仍积累画像；不保存完整输入历史。

画像独立保存在本机免备份目录；只显示已成功持久化的汇总，写入失败可重试。突然终止时未完成或尚未保存的题目可能不计入。文件损坏时保留原文件并回退普通练习；确认重置只清画像、待提交记录和本进程上一局去重缓存，不更改词库、练习配置或推荐开关。

阅读库本次 **25 篇／253 句**：N5～N1 各 5 篇。24 篇明确标注改编，1 篇正文转录，全部为网上原作衍生。来源、逐篇许可与改编记录见 [阅读来源](docs/reading-sources.md)。分级仅供参考，空等级显示实际缺口。句子忽略标点和排版空白，保留は／へ／を及ー；两种模式都支持提供的原文与完整假名，不推测任意混写。两种模式配置互不重置，屏幕重建恢复；每局词数只影响单词。句子成绩显示完成句数、跳过句数、错误次数和用时，正确率为完成句数÷（完成句数+错误次数），零输入为 0。

原始资源保留 **10,635 词**；排除原文或读音含标点／特殊符号的 357 词后，练习和普通浏览实际提供 **10,278 词**：N5 780、N4 730、N3 1,734、N2 3,134、N1 3,900。长音符「ー」保留，释义中的标点不影响筛选；自定义词库同样筛选，但原始数据仍可在管理页编辑和导出。来自 egg rolls 社区牌组，中文释义、非官方分级，数据许可 CC BY-NC 4.0（非商业）。详见 [来源与处理说明](docs/vocabulary-sources.md)。

练习页顶部同排显示退出、进度和计时，下接进度条；单词区与输入区按键盘上方剩余高度分配留白，移除“答案”标题；输入框右下方提供带图标的跳过。三词按上一词／当前词／下一词排列，答对或跳过时平滑移动。答错可修改，不推进；答案框下可跳过，跳过单独计数，不增加正误次数；零输入正确率为 0。每局随机抽取，词数不足按实际；再次练习保留同组并清零，主动退出进入结算，返回首页清零。屏幕重建恢复本局和当前文本，但不会重新判分；键盘候选窗口由输入法管理，不保证恢复。练习与结果页隐藏应用底部导航。进入新一局自动打开系统键盘，主动收起后点答案框重新打开。本局用时从页面就绪开始，后台暂停、完成停止，重建保留，提前退出停止计时，返回首页或重开清零。系统手势条仍由 Android 管理，底部背景与主题融合。

自定义词库支持增删改与 CSV 导入／导出：[CSV 格式](docs/csv-format.md)。词库存于应用私有目录，旧版数据格式保持兼容。词库与练习选项不参加系统备份；卸载或清除数据会删除，请事先导出自定义词库。

## 开发与安装

Kotlin / Jetpack Compose / Material 3，minSdk 26，compileSdk / targetSdk 37。沿用现有稳定依赖组合：AGP 9.4.1、Gradle 9.6.0、Kotlin Compose 2.2.10、JDK 25。

Android Studio 打开本目录，同步后选择模拟器或已授权 USB 调试的手机，点击 Run。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

第二条需要运行中的模拟器或已连接设备。本机 SDK 为 `D:\Android\Sdk`，JBR 为 `D:\Program Files\Android\Android Studio\jbr`；本机路径和 local.properties 不提交。

[Debug APK](app/build/outputs/apk/debug/app-debug.apk) 使用开发签名，当前为 0.9.4 / versionCode 22。手机开启 USB 调试并授权后可本地安装：

```powershell
D:\Android\Sdk\platform-tools\adb.exe install -r app\build\outputs\apk\debug\app-debug.apk
```

不推送 GitHub，不发布商店，不提交 APK、密钥或缓存。
