# Pixel / Material You 设计规范

## 主题

Android 12（API 31）及以上使用系统 dynamicLightColorScheme / dynamicDarkColorScheme。
Android 8–11 使用柔和蓝色完整浅色、深色回退；由系统浅深色自动选择。本版不提供主题设置。
不读取壁纸，不申请壁纸或网络权限。色值集中在 ui/theme/Color.kt。
业务 UI 只使用 MaterialTheme.colorScheme / typography / shapes。
Material 3 标准稳定组件；不使用实验性 Expressive API。

## 颜色角色

页面使用 surface / onSurface；辅助文字 onSurfaceVariant。
介绍与输入容器使用 surfaceContainer / surfaceContainerLow。
目标与结果重点区使用 primaryContainer / onPrimaryContainer。
主要操作使用 primary；输入使用 Material 3 OutlinedTextField 和系统输入法。
错误同时使用 error 与明确文字“还不对，再试一次”，不靠颜色独立传递信息。
结果中正确率是正确次数除以有效作答次数；零输入为 0。同一输入修订不重复计分。

## 形状、排版与间距

页面横向边距 20dp；内部间距以 8dp、16dp、24dp 为主。
大卡片使用 extraLarge 28dp，large 24dp；操作按钮采用 Material 3 默认胶囊形。
系统默认字体与系统日文字体回退，不捆绑字体。
目标日语词条使用 headlineLarge，可换行，结果正确率 displaySmall，标题 headlineLarge / titleLarge。
主要按钮最小高度 56dp，返回图标触摸区 48dp。内容可滚动，按钮允许随字号增高。

## 页面

首页只展示现有练习，不放未实现功能入口。
练习页顺序为退出与进度、日语词条、辅助读音和中文释义、标准文本框、文字反馈与计数。
不绘制或捆绑内置键盘。长期使用用户在系统中自行选择、可更换的输入法，不绑定品牌；布局与候选转换由输入法负责。当前按 0.9.1 逐字判断，包含组合假名；键盘完成键不提交。
错误保留输入供修改；反馈位于输入框之后，不改变前方题目和输入框位置。
结果显示正确率、两类计数、再次练习和返回首页。

## 交互与系统融合

使用 Material 标准 ripple 按压反馈，无延时或阻塞动画，无改变触摸区域的缩放。
enableEdgeToEdge 配合 safeDrawingPadding，内容避开状态栏、导航栏与挖孔。
浅深系统栏图标由 Activity edge-to-edge 根据系统模式管理。
练习使用 TextFieldValue 保存文本与光标，通过标准输入连接支持组合、候选转换和重新编辑。页面使用 imePadding 与可滚动布局避开键盘；退出按钮提供“退出练习”文字，
反馈使用 polite live region；其他按钮使用可见文本标签。
屏幕重建通过 rememberSaveable + 自定义 Saver 保存页面、计数和反馈；主动退出不保留历史。

## 验证要求

三页面浅深主题；Android 12+ 两套系统配色重开；Android 11 或更低实际回退；
360dp 与 150% 字体；手势导航；旋转与中途退出。
预览、设备自动测试、截图目检、真机测试必须分别记载。详见 acceptance.md。

## 后续品质目标（规划，未验收）

- 分区以打字、学习、选项为主；用留白、字号、表面色和必要分隔组织主次，减少卡片嵌套、重复标题和常驻说明。练习保持专注，低频操作按需展开。

## v0.5.0 练习与结算（覆盖前述冲突条目）

- 三词按左／中／右平移，使用固定词条键与可打断的 220ms 位置、缩放、颜色过渡。中间字号最大，下一个灰色；上一词答对浅绿，跳过浅红并明确标“已跳过”，不把跳过伪装为错误作答。首词左侧与末词右侧留空；长词最多三行，保留完整无障碍文本。

- 答案标题、最大 280dp 输入框、进度与图标计数居中，输入框下方提供至少 48dp 跳过按钮，移除“日语打字”。
- 提前退出确认后冻结计时并进入结算；结算内容居中，正确率边框，公式采用辅助色与小字号，图标与练习页一致；返回首页固定左下，再次练习固定右下，内容可滚动。
