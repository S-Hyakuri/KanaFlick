UTF-8 CSV 表头固定为：

```csv
id,japanese,reading,meaning_zh,level
my-school,学校,がっこう,学校,N5
my-cat,猫,ねこ,猫,未分级
```

[可下载示例](example-vocabulary.csv)。应用内“管理自定义词库 → 保存 CSV 示例”也可导出示例文件。

- id：1–128 个英文字母、数字、点、连字符或下划线；库内唯一。新建词条自动分配 UUID，编辑保持 id。
- japanese：必填日语原文，最多 120 字符，不含控制字符。
- reading：必填读音，最多 120 字符，不含控制字符。读音、中文释义及等级的准确性由导入者确认，应用不提供词典自动核验。
- meaning_zh：必填中文释义，最多 1000 字符。
- level：N5、N4、N3、N2、N1 或 未分级，大小写须一致。
- 文件最多 2 MiB、每库最多 10000 词、最多 100 个自定义词库；本机词库文件合计最多 32 MiB。
- UTF-8 可带 BOM；支持 LF/CRLF。逗号、引号和换行须放入双引号字段，内部双引号写成两个双引号。空行跳过。
- 不自动去掉字段首尾空白。相同 id，或 NFC 规范化后原文与读音同时相同，均视为重复并跳过，不更新旧词条。不同 id 的同形异读允许保留。
- 预览显示有效新增数量、重复行、错误行，并展示前 5 条。只要有错误，整批禁止导入；修正后重新选择文件。语法错误导致行边界不可靠时停止解析并显示首次错误。
- 确认导入才追加；取消选择、取消预览、读取失败均不修改已有词库。导入预览在页面重建后需要重新选择文件，不会自动提交。
- 导出包括全部词条及原 id，标准 UTF-8 CSV，所有字段加引号。选择保存位置后写出；取消不写。存储提供方写入失败可能留下不完整目标文件，可重新导出；本机原词库不受影响。
- CSV 是数据交换格式。用电子表格打开不受信任文件时应按文本导入；应用不执行公式，也不擅自改写原文。

词库采用应用私有 noBackupFilesDir 中的版本化二进制文件；写入临时文件、同步、原子替换成功后才显示保存成功。不保存练习历史。读取损坏文件会报错并禁止编辑，不静默清空；卸载/清除数据会删除本机词库。
